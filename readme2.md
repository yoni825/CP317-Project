## About

The **Car Rental System** is a Python-based software project developed for **CP317 – Software Engineering Fundamentals**.  
It allows customers to search for available cars, make reservations, and view their rental history, while giving the rental company the ability to monitor daily rentals, track vehicle utilization, and analyze customer preferences.

### Purpose
The goal of this project is to create a user-friendly platform that simplifies the car rental process for both customers and the company.  
It showcases how team collaboration, iterative development, and software engineering principles can be applied to solve real-world problems.

### Features
**For Customers**
- Search available cars by type or category  
- Reserve cars and manage existing bookings  
- View complete rental history  

**For the Company**
- Monitor daily rentals and vehicle availability  
- Track utilization by car type  
- Analyze customer rental trends and preferences  

### Objectives
1. Design an intuitive interface for customers and staff  
2. Implement a functional reservation and tracking system  
3. Provide data insights for business optimization  
4. Maintain ethical standards around privacy, accessibility, and security
